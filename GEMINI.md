# Workspace Rules (Strict Token Efficiency)
- Concise responses only: short bullets, zero filler, no recaps.
- Only read files explicitly needed for the current milestone. Never scan directories outside the project root unless given an exact file path.
- Make minimal, targeted edits. Never rewrite whole files when a small diff works.
- Keep architecture flat and simple (max 6-7 source files). No over-abstraction, no unused plugins, no telemetry, no online downloaders.
- Stop and ask before installing heavy dependencies or editing Windows system/registry settings.
- Do not write sprawling test suites or long markdown docs unless asked.
